# Data Structures in C++

This repository contains my C++ implementations of fundamental data structures and mathematical constructs. All structures were implemented from scratch without using the standard library containers, for the purpose of strengthening understanding in memory management, algorithm efficiency, and system-level logic.

## 📂 Implemented Structures

- **Linked List**
  - Basic operations (insert, delete, traversal)
  - Polynomial addition using linked list
- **Hash Table**
  - Open hashing with chaining
  - Custom `operator[]`, collision handling, and performance testing
- **Red-Black Tree**
  - Full insertion & deletion logic with balancing
- **Matrix3x3 / Vector3**
  - Arithmetic operations and operator overloading
  - Vector norm, matrix inversion, and multiplication
- **Young Tableau**
  - 2D min-heap structure with `insert` and `extract-min`

## 🔧 Environment
- Language: C++
- Tested on: Windows (g++) / Linux (g++)

## 📌 Notes
These implementations were developed as part of academic exercises and personal study. They aim to provide an educational reference and demonstrate my proficiency in low-level logic construction.
